# Mycelium VS Code Extension

Minimal side panel matching the Mycelium Stitch `06-side-panel` mockup.

## Develop (F5)

1. Install deps and compile:

```bash
cd apps/vscode
npm install
npm run compile
```

2. Open this folder (`apps/vscode`) in VS Code / Cursor.
3. Press **F5** (Run → Start Debugging) to launch an Extension Development Host.
4. In the new window, open the **Mycelium** activity bar icon, or run **Mycelium: Open Panel** from the command palette.

## Notes

- Webview UI lives in `media/panel.css` + HTML generated by `MyceliumViewProvider`.
- Requires VS Code `^1.85.0`.
