# Product Hunt draft

**Name:** Mycelium  
**Tagline:** Local-first codebase context for AI coding — index once, spend fewer tokens  
**Topics:** Developer Tools, Artificial Intelligence, Open Source  

**Description:**
```
Mycelium indexes your repos locally (symbols, files, commits) and returns precise context packets to Cursor and Claude via MCP — so agents stop burning tokens re-grepping the same tree.

• Desktop app (Core bundled) or run from source
• MCP bridge for agent workflows
• Optional Thinking Vault for decisions/ADRs — not a chat journal
• Privacy default: localhost

Built for developers who want indexed retrieval and token efficiency — not another “we remember your conversations” product.
```
